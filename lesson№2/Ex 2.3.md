## 📖 Вправа 2.3 — Множина іменників (Plural of Nouns)

### 🎯 Завдання
Утворіть форму множини поданих іменників.

---

### ✅ Виконання

| Однина (Singular) | Множина (Plural) |
|:---:|:---:|
| brother | brothers |
| teacher | teachers |
| pineapple | pineapples |
| computer | computers |
| pen | pens |
| pencil | pencils |
| table | tables |
| dog | dogs |
| book | books |
| son | sons |

---

### ⚠️ Винятки

Якщо слово закінчується на:
- `-s, -ss, -sh, -ch, -x, -z`

то додається закінчення **-es**:

| Однина | Множина |
|:---:|:---:|
| bus | buses |
| box | boxes |
| watch | watches |
