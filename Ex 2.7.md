## 📘 Правило: Різниця між конструкціями

| Конструкція | Значення | Приклад |
|:---|:---|:---|
| **This + іменник + is + прикметник** | Опис предмета | *This book is interesting.* |
| **This is + a/an + прикметник + іменник** | Називання предмета | *This is an interesting book.* |

### 📌 Порядок слів:

**Правильний порядок:**
This is + a/an + прикметник + іменник.

**Приклади:**
- ✅ *This is a sweet melon.*
- ✅ *This is a black hat.*
- ✅ *This is an interesting book.*

### 📌 Артиклі:
- **a** — перед приголосними: *a cat, a book, a pen, a hat*
- **an** — перед голосними (a, e, i, o, u): *an apple, an interesting book, an empty flat*
